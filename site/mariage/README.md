# mariage

Page web pour un client qui va se marier.

## Le projet

- Le site sera construit en **plusieurs cartes**, comme des slides de présentation, mais sous forme de site : on passe d'une carte à l'autre en faisant défiler.
- J'ajouterai un **formulaire Google Forms** pour que les invités puissent répondre.

## Comment il avance

Le site avance petit à petit. J'ajoute et je modifie les cartes au fur et à mesure que le client me dit ce qu'il veut changer ou ajouter.

## Confidentialité

Les noms, la date, le lieu et l'illustration de cette version publique sont **fictifs** ou modifiés, pour protéger la vie privée du client.
