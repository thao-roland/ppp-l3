# site

Ce dossier accueillera les sites web que je réalise.

Chaque site aura son propre sous-dossier, avec son propre `README.md` qui le présente.

Avant d'ajouter un site ici, je retire tout ce qui ne doit pas être public : photos de personnes, données personnelles, liens privés et secrets.

## Confidentialité des clients

Pour protéger la vie privée de mes clients, les informations qui les concernent sont **modifiées ou remplacées par des informations fictives** dans ce dépôt (noms, photos, dates, lieux, textes personnels, liens). Je ne publie rien sur un client sans son accord.
