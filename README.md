# ppp-l3

Dépôt de mon **PPP de L3** (projet personnel et professionnel). Il regroupe les travaux que je présente pour illustrer mon parcours et mon projet d'activité freelance.

## Dossiers

| Dossier | Description |
| --- | --- |
| [`prospection/`](prospection/) | Outil de suivi de ma prospection freelance, **en cours de réalisation** (étape 1 sur 6 faite), et emplacement des futurs exports CSV anonymisés dans [`prospection/donnees/`](prospection/donnees/). Aucune donnée pour l'instant. |
| [`site/`](site/) | Les sites web que je réalise, un sous-dossier par site. Premier site en cours : [`site/mariage/`](site/mariage/). |

## Confidentialité

Aucun secret ni aucune donnée personnelle n'est versionné. L'absence de secrets est vérifiée avec [gitleaks](https://github.com/gitleaks/gitleaks).
